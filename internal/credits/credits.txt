# Who made Glider PRO.
#
# Transcribed from GliderPRO/README.md lines 2 and 7-15, which is where the source release
# says it in words. The 1994 program does say some of it on screen, and it took this port
# four stages to notice: PICT 153, the plate at the top of the About box, reads "Extreme
# thanks to: Paul Finn, Steve Sullivan & Ward Hartenstein" (docs/analysis/ui-dialogs.md
# 10.6). That is three of the six house authors below, one of them under the alias, painted
# into picture data -- a credit the original gives, and not one anything can read at runtime.
# Which is why this is a file: there is no credits screen to copy and a house has no author
# field.
#
# It is a data file rather than a Go literal so that it can be checked against its source.
# credits_test.go reads the vendored README and fails if a person named here is not named
# there, or if a house named there is not named here -- which is the only way a file like
# this stays true after somebody edits it. [this port] is the port's own and is not in that
# README, so it is held to levels/ instead: every house there has a row here, and a house
# somebody contributes gets one with their name (CONTRIBUTING.md, "Whose house it is").
#
# Syntax: `[Section]`, then `who | what`, then any line with no `|` as a note. Lines are
# not wrapped when drawn, and the shell's test fails one too wide for the screen.

Jonathan Chin signs his houses as Paul Finn, which is the name their own banners carry.
Six houses are credited to nobody: Art Museum, California or Bust!, Castle o' the Air,
Empty House, Fun House and Sampler. The third of those names John Calhoun in its banner,
and Sampler -- saved in 2000, five years after the rest -- names only "Omid".
